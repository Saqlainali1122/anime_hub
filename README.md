# Anime Hub

A mobile-first, original dark anime/media catalog inspired by common streaming directory interaction patterns. It includes a cinematic hero, original avatar, slide-out menu, search bar, category navigation, thumbnail cards, detail pages, storyline/info panels, year, genre, status, seasons, episode count, language/audio, studio/network, release date and duration fields, a 4-image gallery, episode rows, 480p/720p/1080p authorized link buttons, skeleton loading style, and fixed bottom navigation.

## Upload to GitHub, Vercel, or Netlify

Extract the ZIP and upload this exact structure to the repository root:

```text
index.html
README.md
.gitignore
assets/
  hero-bg.jpg
  anime-hub-avatar.jpg
```

Vercel/Netlify can deploy it as a static site. No build command is required. The publish directory is the repository root.

## Owner panel

Open the menu and choose **Owner panel**. Demo password:

```text
saqlainali1122
```

This static demo stores new entries in the current browser's localStorage. It is not a secure public admin system; a shared owner panel for all visitors needs a backend database. The owner form accepts one main thumbnail/poster and up to four gallery image URLs, plus storyline, year, genre, and authorized quality links.

## Legal use

Add only content you own, have permission to distribute, public-domain/Creative Commons material, or official streaming, trailer, purchase, and game-store links. Do not add unauthorized copyrighted downloads.
